## Required producer contract

For each positively verified bot, #176 orders `(sessionEpoch, mapGeneration, membershipGeneration, leaderRevision)` lexicographically. `groupGuid`, `leaderGuid`, map ID, race and stage are equality/decision facts, not ordering keys. The producer must issue a new nonzero value **before** a context can be reused; lower-order values may reset only after a higher-order value increases. No value may wrap/recur while a tracker could retain its tombstone or delayed callback. An old callback must carry the old captured tuple, not query the new live tuple. Equal conflicting facts yield `Ambiguous`; lower version yields `Stale`; both refuse a temporary override.

`GroupScript.cpp` invokes hooks synchronously at each Core call site; this does **not** establish that all callers execute on one map/world thread, nor that delayed leave, Playerbots and session callbacks share a queue. Pinned Playerbots `RandomPlayerbotMgr::IsRandomBot(lowGuid)` reads mutable `currentBots`, whose add/remove/update paths are separate; it is a login-source proof, not a worker-safe lookup. Full actor/session ownership requires tracing every caller of `Group::AddMember/RemoveMember/ChangeLeader/Disband`, map transfer and reconnect on the exact installed tuple. No producer should be invented from arrival order or wall-clock time.

## Minimal evidence needed before a runtime adapter

1. A source map of every group/move/reconnect callback call site and its executor/queue; prove exactly where old facts are copied and where new versions are published.
2. A per-bot or global non-reusing issuer for membership and leader revisions, a complete map-generation issuer, and a process/session incarnation fence; define overflow and restart behavior.
3. A callback quiescence/ownership proof for any tombstone retirement. Without one, retain hard saturation and report capacity as no temporary view.
4. An exact earned-stage read and verified RandomBot lease at event time; teardown may use captured old identity after proof loss, but must not create blind tombstones for arbitrary unobserved bots.
5. Macro-ON native Worldserver link and in-game join/leave/kick/disband, A→B→A transfer, leader away/back, logout/rebind, cap/earned-stage and delayed callback tests on the actually installed source tuple. OFF-path regressions remain mandatory.

No Core, Playerbots, Claude social runtime, config, SQL, DB, client or live-server file was changed for this audit. The #176 pure model stays unwired.
